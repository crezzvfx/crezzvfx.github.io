Lumbuang Ameh Kebijakan Privasi Ketentuan Layanan

Kebijakan Privasi

Berlaku sejak 6 November 2026

Kebijakan ini menjelaskan cara aplikasi desktop Lumbuang Ameh memakai data channel YouTube. Aplikasi ini dipakai secara internal oleh pengelola channel (Administrator) atas izin pemilik channel.

Layanan API YouTube

Lumbuang Ameh menggunakan layanan API YouTube. Dengan memberi izin, pemilik channel juga tunduk pada Ketentuan Layanan YouTube. Data yang diproses Google mengikuti Kebijakan Privasi Google.

Data yang diakses

Aplikasi meminta tiga izin baca:

  • youtube.readonly: nama dan ID channel, jumlah total views, subscriber, dan video, serta judul video.
  • yt-analytics.readonly: statistik harian channel dan statistik per video, seperti views, watch time, rata-rata durasi tonton, likes, jumlah komentar, jumlah share, dan perubahan subscriber.
  • yt-analytics-monetary.readonly: estimasi pendapatan channel dan video.

Aplikasi tidak meminta atau menyimpan password Google, dan pada izin saat ini tidak bisa mengubah apa pun di channel. Aplikasi juga tidak menyimpan isi komentar.

Cara data dipakai

Data hanya dipakai untuk menampilkan statistik dan estimasi pendapatan channel tersebut kepada pengelolanya. Data tidak digabungkan antarchannel.

Data tidak dijual, tidak dipakai untuk iklan, tidak dipakai untuk menilai kelayakan kredit, dan tidak dipakai untuk melatih model AI.

Siapa yang bisa melihat data

Data hanya bisa dilihat oleh orang yang memakai PC tempat aplikasi berjalan dan channel itu terhubung, yaitu Administrator yang ditunjuk pemilik channel. Data tidak dikirim ke server milik aplikasi, karena aplikasi tidak memilikinya. Aplikasi hanya berkomunikasi dengan layanan Google untuk login dan mengambil data.

Administrator dapat menyampaikan statistik channel kepada pemilik channel tersebut.

Penyimpanan di perangkat

Aplikasi menyimpan data di perangkat tempatnya berjalan, dan tidak memakai cookie atau iklan pihak ketiga.

  • Token izin Google disimpan di penyimpanan aman Windows pada PC tersebut, tidak di database aplikasi.
  • Statistik disimpan di file database lokal pada PC tersebut. File ini tidak dienkripsi tersendiri, sehingga perlindungannya mengikuti keamanan PC dan akun Windows.
  • Koneksi ke Google memakai HTTPS. Aplikasi juga dilindungi login lokal, dan password login itu disimpan dalam bentuk hash.

Masa simpan

  • Catatan statistik publik per menit: dihapus setelah 7 hari.
  • Judul dan statistik video yang tidak diperbarui: dihapus setelah 30 hari.
  • Statistik harian dan estimasi pendapatan: disimpan selama channel terhubung agar perbandingan periode bisa dilakukan.
  • Token izin: disimpan selama channel terhubung.

Mencabut izin dan menghapus data

Pemilik channel dapat mencabut izin kapan saja lewat halaman izin akun Google.

  • Lewat aplikasi: tombol putuskan channel mencabut izin di Google dan menghapus data channel itu dari PC.
  • Lewat akun Google: data channel dihapus dari PC paling lambat 30 hari setelah izin dicabut.
  • Atas permintaan: pemilik channel dapat meminta penghapusan data, dan permintaan diproses paling lambat 7 hari.

Menghapus data dari aplikasi tidak memengaruhi data apa pun di YouTube.

Perubahan kebijakan

Bila aplikasi nanti memakai data dengan cara baru, misalnya membalas komentar atau memberi akses kepada pengelola lain, kebijakan ini diperbarui lebih dulu dan pemilik channel diminta menyetujuinya kembali.

Kontak

Pemilik channel dapat menghubungi Administrator yang mengelola channelnya secara langsung. Pertanyaan atau keluhan privasi lainnya dapat disampaikan lewat halaman Issues proyek ini. Halaman itu terbuka untuk umum, jadi jangan menuliskan data pribadi di sana.
