Lumbuang Ameh

Aplikasi desktop Windows untuk membantu pengelola melihat statistik channel YouTube yang pemiliknya telah memberi izin.

Ini aplikasi internal skala kecil, bukan layanan untuk umum. Halaman ini tidak menyediakan pendaftaran, unduhan, atau login.

Yang dilakukan aplikasi

  • Menampilkan statistik satu channel: views, watch time, subscriber, likes, komentar, dan share.
  • Menampilkan estimasi pendapatan channel beserta perubahannya dibanding periode sebelumnya.
  • Menampilkan ranking video dan grafik perkembangan channel.
  • Menampilkan ringkasan asal penonton, negara, jenis konten, serta usia dan gender penonton dari YouTube.

Kenapa aplikasi meminta izin Google

Data di atas hanya tersedia lewat layanan API YouTube dengan persetujuan pemilik channel. Pemilik channel memberi izin baca di halaman resmi Google. Aplikasi tidak pernah meminta atau menyimpan password Google, dan izin itu bisa dicabut kapan saja.

Saat ini aplikasi hanya meminta izin baca, sehingga tidak bisa mengubah channel, video, atau komentar.

Di mana data disimpan

Data disimpan di PC yang menjalankan aplikasi. Aplikasi tidak memakai server sendiri. Rinciannya ada di Kebijakan Privasi.
